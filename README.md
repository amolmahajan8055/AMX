
# AI Career & Program Advisor - CodeKerdos

This project merges the original Career Assessment / Sales Tracker flow with the new 30-question objective GenAI/FDE readiness assessment.

## What is included

- Candidate name, email, mobile, experience, current role
- Current CTC and target CTC
- Job-switch timeline and interview stage
- Career goal / target role
- Candidate's **initial course preference captured before the test**
- 0–10 self-ratings across:
  - Machine Learning
  - Python
  - Neural Networks
  - RAG
  - AI Agent Development
  - Agentic AI / Multi-Agent Workflows
  - GenAI / LLMs
  - Cloud (AWS / Azure)
  - Model Monitoring / Observability
  - Security Best Practices
  - Development
  - Backend / APIs
  - Testing / Evaluation / Guardrails
  - Communication /presentation/story line
  - Project Delivery
  - PoCs / Demos / Presales Activities
  - Client / Stakeholder Management
  - Team Leading / Team Building
  - Deployment
- Weekly commitment, growth preference and willingness to push
- 30 advanced scenario-based MCQs
- Objective competency scores
- Self-rating vs objective-score comparison
- Four-program routing:
  1. 1-Month Interview Accelerator - interviews, project storylines, resume, LinkedIn and Naukri optimization, mock interviews and feedback
  2. 2-Month Career Accelerator - core GenAI concepts, projects and storylines from scratch, development, deployment, monitoring, security, introductory fine-tuning, and every service in the interview accelerator
  3. 4-Month GenAI / Data Science Foundation Program - complete foundations, hands-on projects and production skills
  4. 4-Month Forward Deployed Engineer (FDE) Program - complete foundations, enterprise projects, production skills and client delivery
- Personalized summary
- Optional OpenAI-generated summary with deterministic fallback
- Advisor name, lead status, payment status, follow-up plan/date
- One-line call conclusion and internal notes
- CSV-based sales tracker
- Candidate TXT report download
- Optional Brevo API email

## Run locally

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate

pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Optional: enable live AI-written summary

The recommendation itself always comes from the deterministic rules engine.

If you want the final narrative summary to be generated by an OpenAI model:

```bash
set OPENAI_API_KEY=your_key_here
set OPENAI_MODEL=gpt-5-mini
streamlit run streamlit_app.py
```

If the key is missing or the API call fails, the app automatically uses the built-in deterministic personalized summary.

## Optional: email reports with Brevo

Create a Brevo account, verify your sender email, and create an API key. Set these values in the local `.env` file:

- `BREVO_API_KEY`
- `BREVO_FROM_EMAIL` (the verified sender)
- `BREVO_FROM_NAME` (defaults to CodeKerdos)

Report email uses the Brevo HTTPS API; SMTP credentials are no longer needed. Keep the API key private. The report screen and TXT download work without email configuration. A successful API response confirms acceptance for delivery, not inbox delivery.

## Recommendation philosophy

The app deliberately avoids recommending a course only from the candidate's self-rating.

The routing combines:
- objective MCQ result,
- competency distribution,
- production readiness,
- self-rating,
- experience,
- career direction,
- switch timeline,
- weekly commitment,
- willingness to push,
- initial course preference.

The final AI/LLM layer explains the result; it does not decide the course.

## Accelerator eligibility and direct enrollment

The assessment score establishes the readiness band, while practical exposure and behavioral readiness determine whether a short intensive program is suitable:

- 80% and above: 1-Month Interview Accelerator when the candidate also has high learning agility, relevant project/deployment exposure, 7-10+ weekly hours and willingness to push intensively.
- 70%-79%: 2-Month Career Accelerator when the candidate also has good learning agility, practical exposure, at least 4-6 weekly hours and readiness for consistent additional effort.
- 50%-69%: 4-Month FDE Program for deeper hands-on engineering, deployment, production and client-facing exposure.
- Below 50%: 4-Month Data Science / GenAI Foundation Program for structured learning from the basics.

Candidates scoring 80% or higher who meet the two-month criteria but not the more intensive one-month criteria receive the two-month recommendation. Candidates in a short-program score band who do not meet its non-score requirements receive the four-month FDE recommendation. Score or self-rating alone never unlocks a short program.

Candidates can still select either four-month program without a technical test. The report marks readiness as not assessed.

## Private sales tracker

Candidates can complete an assessment and view/download only the report held in their own browser session. The Sales Tracker button is disabled until staff sign in. Staff login is in the sidebar.

On first launch, the app creates an `admin` account and writes its random initial password to `data/admin_setup.txt`. Open this local file, sign in, change the admin password, and remove the setup file. Account Management lets the admin generate/reset unique passwords for `aman`, `sales02` through `sales10`, and edit executive display names. Passwords are stored as salted PBKDF2 hashes; reset passwords are shown only once. Sessions expire after eight hours and are revoked on password changes. Five failed login attempts lock an account for five minutes.

Each sales executive sees only records assigned to their sales ID, including exports and saved reports. Admin sees all records and can assign/reassign ownership. Each executive gets an opaque `?ref=...` candidate link in the sidebar: append it to the app URL before sharing with their candidates. Reports completed through that link are automatically assigned to the executive. Reports without a link are unassigned and visible only to admin. A referral link grants submission attribution, never tracker access.

Data is stored in `data/private_tracker.sqlite3`. Existing `data/call_records.csv` rows are imported once as unassigned/admin-only; advisor names are never treated as proof of ownership. New records use the private database. Keep the database and setup file on the server; sharing the raw CSV or project data folder bypasses app login controls. Static file serving is disabled.

Validate access controls with `python -m unittest test_tracker_security test_program_eligibility`.

## Follow-up reminders and candidate report sharing

Staff receive popup reminders after login for their own calls due today, tomorrow or overdue. The reminder list refreshes every 60 seconds while the app is open. Admin can see reminders across accounts. These are in-app reminders, not background email/SMS notifications while signed out.

In Sales Tracker, select a saved candidate and record the call activity, new outcome, lead status and next follow-up. One-week and one-month plans calculate the next date on submission; a custom date can override the plan. No follow-up clears the next date. Completed/no-answer/rescheduled calls require an update. Each save appends a timestamped history entry with the executive, outcome and old/new follow-up dates.

Candidates see their submitted profile/self-ratings and every assessment question, options, selected answer, correct answer and correctness result. The TXT download and Email my complete report include the same review. Email uses the configured Brevo API; without Brevo settings the screen report and TXT download remain available. No staff notes or other candidates' information are included.

## Current staff email option: SMTP

Staff can check **Email report to student** when saving a call record. This sends the complete report in the message and as a TXT attachment using SMTP. Set `SMTP_HOST`, `SMTP_PORT`, `SMTP_USERNAME`, `SMTP_PASSWORD`, and `SMTP_FROM_EMAIL` in `.env`. Port 587 uses STARTTLS; port 465 uses implicit TLS. The current checkbox uses SMTP, not Brevo. Downloading remains available without email settings.

## Streamlit deployment admin login

In the deployed app's Settings > Secrets, add `ADMIN_PASSWORD = "your-private-password-of-at-least-12-characters"`. Sign in with ID `admin`. The secret configures an existing or new admin account; changing the secret resets its password and revokes prior admin sessions. Never commit `.env`, `admin_setup.txt`, databases or `.streamlit/secrets.toml`. Local password resets do not update the deployed database.

Streamlit-hosted local SQLite storage can be lost when the app is rebuilt. Use persistent external storage before relying on the deployment for long-term candidate records and sales accounts.
